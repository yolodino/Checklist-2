TRADECHECK — UPDATED GITHUB PAGES VERSION

1. Unzip this download.
2. Open your existing GitHub repository (trading-checklist).
3. Upload/replace all files in this ZIP directly in the repository root.
4. Commit changes to main. GitHub Pages should redeploy automatically.
5. Refresh your site in Safari. If the old version remains, close the app fully,
   reopen the website, and refresh. You may need to remove and re-add the
   Home Screen shortcut using Safari > Share > Add to Home Screen.

Features: revised “Hit HTF level” condition; 10-item checklist; completion
progress ring; timestamped completion journal; reset without deleting records;
delete individual records; clear all with confirmation; CSV export; local
storage; offline caching.

DATA: Journal and checklist are stored locally in this browser/device. The app
keeps its own v2 storage keys and attempts migration from several common older
journal keys. Keep a backup of your old repository before replacing files.
Do not clear Safari website data if you need to preserve locally stored data.
